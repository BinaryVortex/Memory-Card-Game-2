# Memory Card Game

Memory Card Game built with HTML, CSS and JavaScript.

![Gameplay screenshot](https://raw.githubusercontent.com/BinaryVortex/Memory-Card-Game-2/main/Screenshot%202024-09-02%20225549.png)

## Overview

A simple, responsive memory (matching) card game where players flip cards to find matching pairs. This project is ideal for beginners learning DOM manipulation, event handling, and basic game logic in vanilla JavaScript.

## Features

- Clean, minimal UI built with HTML & CSS
- Simple game logic implemented in JavaScript
- Responsive layout that works on desktop and mobile
- Move counter and basic timer (if implemented in the app)

## How to play

1. Open `index.html` in your browser.
2. Click any card to flip it and reveal the icon/image.
3. Flip a second card to try and find its match.
4. If the two cards match, they stay revealed; otherwise they flip back over.
5. Repeat until all pairs are found.

## Run locally

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Memory-Card-Game-2.git

2. Open the project folder and double-click `index.html`, or serve it with a local dev server (recommended for testing assets):

   - Using Python 3: `python -m http.server 8000`
   - Then visit `http://localhost:8000` in your browser.

## File structure

- `index.html` — Game markup
- `style.css` — Styling and responsive layout
- `script.js` — Game logic and interactivity
- `Memory.jpg` / `Screenshot 2024-09-02 225549.png` — Screenshots used in the README

## Customize

- Edit `style.css` to change colors, card sizes, and layout.
- Modify `script.js` to adjust difficulty, add a scoring system, or add animations.
